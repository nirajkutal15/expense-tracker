# 💸 Expense Tracker

===

# 

# A full-stack expense tracking application built with Java Spring Boot and React.js

# 

# \## Tech Stack

# \- Backend: Java, Spring Boot, REST APIs, JWT Authentication

# \- Frontend: React.js, TypeScript

# \- Database: MySQL, PostgreSQL

# \- Tools: Docker, AWS, Postman

# 

# \## Features

# \- User registration and login with JWT

# \- Add, edit, delete expenses by category

# \- Budget management

# \- Receipt tracking

# \- Secure REST APIs

# 

# \## How to Run

# \### Backend

# cd "Spring boot/tracker"

# mvn spring-boot:run

# 

# \### Frontend

# cd Frontend

# npm install

# npm start
